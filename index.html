Sobre o projeto

O BioAcesso é um protótipo acadêmico para demonstrar conceitos de identificação facial e organização de níveis de acesso.

O navegador utiliza o backend Flask para executar o processamento facial com OpenCV e LBP. Este protótipo é acadêmico e não deve ser usado para decisões reais de acesso.

Como funciona esta etapa?

A avaliação compara as imagens da pasta base/teste com as referências cadastradas e calcula a taxa de acerto.

A avaliação agora é executada pelo backend. Coloque as imagens de teste nas pastas indicadas e clique no botão abaixo.

Estrutura esperada dos dados

base/\n├── referencia/\n│   ├── pessoa_01/\n│   └── pessoa_02/\n└── teste/\n    ├── pessoa_01/\n    ├── pessoa_02/\n    ├── desconhecido/\n    └── invalido/

O que avaliar

  • Taxa de reconhecimento correto.
  • Falsas aceitações e falsas rejeições.
  • Tempo de processamento.
  • Comportamento com imagens sem face detectável.
